# Digital Payments Transaction Analysis Dashboard

## 📌 Objective
This project analyzes digital payment transactions to identify trends in transaction behavior, performance, and operational efficiency.

## 🛠 Tools Used
- Power BI
- SQL (optional)
- Excel

## 📊 Key Metrics
- Total Transaction Value
- Total Number of Transactions
- Transaction Success Rate
- Average Transaction Value

## 🔍 Key Insights
- Android users aged 26–45 contribute the highest transaction value
- Peak transaction activity occurs between 12 PM and 8 PM
- P2P transactions dominate overall transaction volume
- Certain network types show higher transaction failure rates

## 📁 Files Included
- Power BI Dashboard (.pbix)
- Exported Dashboard (.pdf)
- Dataset (.csv)

## 💡 Business Impact
This dashboard simulates real-world financial transaction monitoring used in banking and payment operations, helping stakeholders make data-driven decisions.
